=====================REGULAR EXPRESSION ==================
A Regular Expression (Regex) is a pattern used to search, match, or manipulate text.
It is commonly used in programming, data validation, and text processing.

| Symbol | Meaning              | Example                   |
| ------ | -------------------- | ------------------------- |
| `.`    | Any single character | `a.b` → aab, acb          |
| `\d`   | Any digit            | 0–9                       |
| `\w`   | Word character       | a–z, A–Z, 0–9             |
| `\s`   | Space                | whitespace                |
| `+`    | One or more          | `a+` → a, aa, aaa         |
| `*`    | Zero or more         | `ab*` → a, ab, abb        |
| `?`    | Optional             | `colou?r` → color, colour |
| `^`    | Start of string      | `^Hello`                  |
| `$`    | End of string        | `world$`                  |

validators in mongooese : check if the data is correct before saveing it. it the data does not meet the rules. mongoose throws a validation error and the document is saved.

1. required validator 
name:{
    type:string,
    required:true
}
custom message:
name:{
    type:String,
    required:[true:"Name is required"]
}

2. minLength validator:
minimum number of character for strings.
userName:{
    type:String,
    minLength:3
}
custom message:
userName:{
    type:String,
    minLength:[3,"username must be at least 3 characters"]
}

3.maxlength validator
maximum allowed characters
userName:{
    type:String,
    maxlength:25
}

4.min validator
minimum value for numbers or data
age:{
type:Number,
max:18
}

5.max validator
maximum value allowed.
age:{
    type:Number,
    max:80
}

6. enum validator
allows only specific values.
role:{
    type:String,
    enum:{"user","admin","manager"}
}

7. unique validator
creates a unique index so values cannot repeat
email:{
    type:String,
    unique:ture
}

8. macth validator 
user regular expression to validator strings.
email:{
    type:String,
    match:[^\S+@\S+\.\S+$,"Please enter a valid email"]
}

9. vaidate(custom validator)
you can create your own validation logic.
for example:
only even numbers are allowed

age:{
    type:Number,
    validate:function(num){
        return num%2 ==0
    },
    message:"Age must be an even number"
}

================== Middleware

Validator with Middleware : means checking the correctness of data automatically before saving or updating in the database.
if the validation fails, middkeware prevents the operation and return an error.

Mongoose provide pre and post middleware.

1. pre middleware runs before an operation happens.
for example:
savedfindByIdAndUpdate

User sends data --> Pre-validation middkeware check data --> if valid --> save to database

2. post middleware runs after an operation cimpletes.
for example:
logging
sending email

save data --> Post middleware runs --> logging/notification
